# 📋 Git Error 분석 보고서: `src refspec main does not match any`

본 보고서는 `git push` 실행 시 발생하는 `error: src refspec main does not match any` 및 `failed to push some refs` 에러의 근본 원인을 분석하고, 상황별 즉각적인 해결책을 제시합니다.

## 1. 에러의 핵심 의미
이 에러는 **"로컬 저장소에서 `main`이라는 이름의 브랜치(또는 참조)를 찾을 수 없어, 원격 저장소(remote)로 보낼 대상이 없다"**는 뜻입니다. 즉, Git이 전송할 '소스(src)'가 존재하지 않는 상태입니다.

## 2. 주요 발생 원인 분석

### ① 로컬에 커밋(Commit)이 없는 경우 (가장 빈번)
*   **현상:** `git init`으로 저장소를 새로 만든 후, 파일을 `git add`는 했으나 `git commit`을 한 번도 수행하지 않은 상태에서 `push`를 시도할 때 발생합니다.
*   **이유:** Git에서 브랜치는 커밋을 가리키는 포인터입니다. 첫 번째 커밋이 생성되기 전까지는 `main`이라는 브랜치 자체가 실질적으로 존재하지 않는 상태(unborn branch)로 간주됩니다.

### ② 브랜치 이름 불일치 (`master` vs `main`)
*   **현상:** 로컬 브랜치 이름은 `master`로 생성되었는데, 명령어를 `git push origin main`으로 입력한 경우입니다.
*   **이유:** 과거 Git의 기본 브랜치 명칭은 `master`였으나, 최근 표준은 `main`입니다. 환경 설정에 따라 로컬은 `master`인데 명령은 `main`을 찾고 있어 참조 오류가 발생합니다.

### ③ 브랜치 생성 및 체크아웃 미비
*   **현상:** 특정 브랜치에서 작업 중이며, `main` 브랜치로 전환(checkout)하거나 생성하지 않은 상태에서 `main`을 push하려고 할 때 발생합니다.
*   **이유:** 현재 작업 중인 브랜치(HEAD)와 명령어로 지정한 브랜치(`main`)가 물리적으로 분리되어 있습니다.

## 3. 상황별 해결 가이드 (Action Plan)

### [Case 1] 첫 커밋을 하지 않은 경우 (초기 세팅 중)
가장 먼저 로컬에 변경 사항을 확정(commit)해야 합니다.
```bash
git add .
git commit -m "Initial commit"
git push origin main (또는 master)
```

### [Case 2] 브랜치 이름이 `master`로 되어 있는 경우
로컬 브랜치 이름을 `main`으로 변경하여 일치시킵니다.
```bash
# 1. 현재 브랜치 이름 확인
git branch

# 2. 현재 브랜치(master)를 main으로 강제 변경
git branch -M main

# 3. 다시 Push 시도
git push -u origin main
```

### [Case 3] 원격 저장소와 로컬의 상태가 꼬인 경우
원격의 내용을 먼저 가져온 뒤 재시도합니다.
```bash
git pull origin main --allow-unrelated-histories
# 충돌 해결 후
git push origin main
```

# 🛠 Git Push Error 해결을 위한 단계별 명령어 세트

`error: src refspec main does not match any` 에러는 로컬 저장소에 커밋된 내용이 없거나, 푸시하려는 `main` 브랜치가 존재하지 않을 때 발생합니다. 아래 명령어를 순서대로 터미널에 입력하십시오.

git branch

# 2. 모든 변경 사항을 스테이징 영역에 추가
git add .

# 3. 첫 번째 커밋 생성 (에러의 근본 원인인 '커밋 없음' 상태 해결)
git commit -m "initial commit"

git branch -M main

# 5. 원격 저장소(origin)의 main 브랜치로 푸시 및 업스트림 설정

    git add .
    git 1commit -m "initial commit"
    git push origin main
    ```

### [상황 2] 로컬 브랜치 이름은 `master`인데, 원격은 `main`을 요구하는 경우
*   **증상:** 로컬과 원격의 브랜치 명칭이 불일치함.
*   **즉시 실행 명령어:**

    git push -u origin main
    ```

    git push origin main

| **새로운 콜라겐 망** | 굵고 탄탄하며 촘촘하게 얽힌 3D 매쉬(Mesh) 구조 | 재생 완료 후의 탄력 있는 피부 상태 |

## 2. 단계별 애니메이션 모션 브리프 (Motion Sequence)

### **[Phase 1: 노화의 징후 - Fragmentation]**
- **화면 구성:** 텅 빈 듯한 Slate Gray 공간에 힘없이 처진, 끊어진 콜라겐 섬유들이 떠 있음.
- **움직임:** 중력에 의해 아래로 늘어지는 듯한 느리고 무거운 움직임. 섬유 사이의 간격이 넓어 불규칙한 패턴을 보임.
- **효과:** 채도가 낮은 무채색 톤을 사용하여 '결핍'과 '노화'의 느낌을 강조.

### **[Phase 2: PLLA 투입 - The Trigger]**
- **화면 구성:** 화면 상단에서 Rose Gold 빛을 내는 PLLA 입자들이 정밀하게 하강.
- **움직임:** 입자들이 마치 물방울이 떨어지듯 부드럽지만 목적지를 향해 정확하게 이동(Targeted Motion).
- **효과:** 입자가 진피층(Dermis)에 닿는 순간, 주변의 끊어진 콜라겐 섬유에 미세한 빛의 파동(Ripple Effect)이 전달됨.

### **[Phase 3: 세포 활성화 - Stimulation]**
- **화면 구성:** PLLA 입자와 섬유아세포(Fibroblast)가 접촉하는 클로즈업 샷.
- **움직임:** 세포가 PLLA 입자를 감싸 안으며, 세포 내부에서 빛이 맥동(Pulsing)하기 시작함. 세포의 움직임이 '정지' 상태에서 '활성' 상태로 전환됨.
- **효효:** 세포의 박동에 맞춰 주변 환경의 빛 밝기가 미세하게 변하며 '에너지 생성'을 시각화.

### **[Phase 4: 재건 및 밀도 상승 - Reconstruction]**
- **화면 구성:** 끊어졌던 섬유들이 다시 연결되며 굵고 촘촘한 매쉬 구조를 형성.
- **움직임:** 흩어져 있던 섬유들이 자석에 이끌리듯 서로 엮이며(Weaving), 화면 전체가 탄탄한 그물망 형태로 재구성됨.
- **효과:** 화면의 밀도가 높아짐에 따라 전체적인 밝기가 밝아지며, 최종적으로 완성된 구조물 위로 Rose Gold 광택이 훑고 지나가며 '완성'을 선포.

## 1. 3D Material & Texture Specification (재질 및 텍스처)

### A. PLLA Micro-Particles (입자)
*   **Base Color:** `#B76E79` (Rose Gold Metallic)
*   **Material Properties:**
    *   **Metallic:** 1.0 (완전 금속성)
    *   **Roughness:** 0.15 (매끄러운 광택으로 빛 반사 극대화)
    *   **Anisotropy:** 0.3 (빛이 닿는 방향에 따라 길게 늘어지는 광택 유도)
    *   **Subsurface Scattering (SSS):** 0.05 (입자 중심부에 아주 미세한 빛 투과를 주어 딱딱한 금속이 아닌 '생체 내 입자' 느낌 부여)
*   **Visual Effect:** 입자가 움직일 때 주변의 슬레이트 그레이 배경이 입자 표면에 맺히도록 **Reflections** 설정 필수.

### B. Collagen Fiber Network (콜라겐 구조)
*   **Base Color:** `#E5B1A1` (Soft Rose Gold / Translucent)
*   **Material Properties:**
    *   **Transmission (Transparency):** 0.4 (반투명한 상태)
    *   **Roughness:** 0.3 (입자보다는 거칠게 설정하여 유기적인 질감 표현)
    *   **SSS (Subsurface Scattering):** 0.6 (가장 핵심. 빛이 섬유 내부로 퍼지며 부드럽고 탄력 있는 피부 조직의 느낌을 구현)
*   **Visual Effect:** 입자가 지나간 자리에 끈기 있게 연결되는 실 형태의 네트워크로 표현.

### 2. Lighting Setup
*   **Key Light (Main):** 차가운 화이트 톤의 Spot Light. 입자의 형태(Silhouette)를 잡아주는 역할.
*   **Rim Light (Edge):** 입자 뒤편에서 비추는 강한 로즈 골드 톤의 Rim Light. 입자의 테두리를 빛나게 하여 슬레이트 그레이 배경과 분리(Separation)시킴.
*   **Fill Light:** 매우 낮은 강도의 블루/그레이 톤. 그림자 영역이 완전히 검게 죽지 않도록 미세한 디테일 유지.

---

## 3. Particle Dynamics & Motion Guide (움직임 가이드)

### Phase 1: Injection (주입 단계)
*   **Motion:** 입자들이 일정한 방향성(Z축 방향)을 가지고 빠르게 유입됨.
*   **Physics:** 입자 간의 충돌(Collision)은 최소화하되, 유체(Fluid) 속을 흐르는 듯한 저항감(Drag)을 적용.

### Phase 2: Activation & Interaction (활성화 단계)
*   **Motion:** PLLA 입자가 주변 환경과 부딪히며 에너지를 방출.
*   **Visual Effect:** 입자가 특정 지점에 머물 때 미세한 **'Glow/Bloom'** 효과 발생. 입자 주변으로 아주 작은 로즈 골드 파티클들이 흩뿌려짐(Emitting).

### Phase 3: Collagen Synthesis (합성 단계)
*   **Motion:** 입자 사이를 연결하는 가느다란 선(Collagen Fiber)들이 유기적으로 엮임(Weaving).
*   **Speed:** 매우 느리고 부드러운(Smooth/Organic) 움직임. 마치 세포가 증식하는 듯한 탄성 있는 움직임 구현.

# 🎞️ PLLA 3D 애니메이션 & 브랜드 비주얼 에셋 제작 사양서

CEO의 지시에 따라, 브랜드 정체성(Slate Gray & Rose Gold)을 극대화하고 PLLA의 입자감을 시각적 쾌감으로 전환하기 위한 3D 에셋 제작 기술 사양을 정의합니다.

## 1. 3D 에셋 구성 요소 (Asset Components)

### A. PLLA 입자 시스템 (Core Subject)
- **형태:** 불규칙한 구체(Sphere)들이 결합된 유동적 클러스터. 정적인 상태가 아닌, 미세하게 진동하거나 서로 결합/분리되는 애니메이션 포함.
- **재질 (Shader Settings):**
  - **Base Color:** `#B76E79` (Rose Gold)
  - **Metallic:** `1.0` (완전 금속성)
  - **Roughness:** `0.05 ~ 0.15` (고광택 유기적 질감)
  - **Anisotropy:** `0.3` (금속 특유의 결 방향 광택 추가)
  - **Subsurface Scattering (SSS):** `0.1` (입자 내부로 빛이 살짝 스며드는 느낌을 주어 인위적인 금속 느낌을 상쇄하고 생동감 부여)

### B. 환경 및 배경 (Environment)
- **배경색 (Background):** `#2F4F4F` (Dark Slate Gray) 또는 `#1A1A1A` (Deep Charcoal)로 설정하여 입자의 로즈 골드 빛이 묻히지 않도록 대비 확보.
- **바닥면 (Floor):** 매우 낮은 Roughness(`0.02`)를 가진 검은색 대리석 질감의 Plane. 입자의 반사(Reflection)가 바닥에 맺히도록 설정.

## 2. 라이팅 및 렌더링 가이드 (Lighting & Rendering)

### A. 라이팅 설계 (Three-Point Lighting + HDRI)
- **Key Light:** 차가운 톤의 White/Blue 계열 (입자의 윤곽선(Rim Light)을 잡아내어 배경과 분리).
- **Fill Light:** 부드러운 Rose Gold 톤의 약한 광원 (그림자 영역의 디테일 유지).
- **Rim Light:** 강한 Contrast를 위한 고휘도 포인트 라이트 (입자의 입체감 극대화).
- **HDRI:** Studio Lighting 환경의 HDRI를 사용하여 금속 재질에 자연스러운 환경 반사 유도.

### B. 카메라 설정 (Camera Setup)
- **Lens:** `85mm` 또는 `100mm` Macro Lens (피사체에 집중하고 배경 흐림 효과 극대화).
- **Depth of Field (DoF):** `f/2.8` 이하로 설정. 입자 클러스터의 앞부분은 선명하고 뒷부분은 부드러운 Bokeh로 처리하여 공간감 형성.
- **Motion Blur:** `Shutter Angle 180°` 적용 (입자의 움직임이 끊기지 않고 부드럽게 보이도록 함).

*핵심: 단순한 금색이 아닌, 미세하게 빛을 반사하는 프리미엄 메탈릭 질감*
- **Base Color:** `#B76E79` (Rose Gold)
- **Metallic:** `1.0` (완전한 금속성)
- **Roughness:** `0.15 - 0.25` (매끄러운 광택을 유지하되, 너무 거울 같지 않게 설정하여 고급스러움 유지)
- **Anisotropy (이방성):** `0.4` (빛이 입자 표면을 따라 길게 늘어지는 효과를 주어 미세한 입자감을 강조)
- **Clearcoat:** `0.5` (입자 표면에 얇은 코팅층을 추가하여 액체 속에서도 선명한 하이라이트 생성)

### B. 콜라겐 매트릭스 (The Structure: Collagen Fiber)
*핵심: 생동감 있는 유기적 조직감을 위해 Subsurface Scattering(SSS) 필수 적용*
- **Base Color:** `#F8F_F2` (Brand Cream)
- **Subsurface Scattering (SSS):** `0.3` (빛이 조직 내부로 투과되어 부드럽게 퍼지는 효과. 세포의 생명력을 표현)
- **Transmission:** `0.1` (약간의 반투명도 부여)
- **Roughness:** `0.6` (입자와 대비되는 매트한 질감으로 입자의 광택을 돋보이게 함)

### C. 환경 배경 (The Void: Deep Slate Gray)
*핵심: 입자와 콜라겐이 돋보일 수 있는 깊이감 있는 어두운 공간*
- **Base Color:** `#2F3E46` (Slate Gray)
- **Roughness:** `0.8` (빛 반사를 최소화하여 입자의 하이라이트가 배경에 묻히지 않도록 함)
- **Atmospheric Fog:** `Density 0.05` (입자 주변에 아주 미세한 안개를 배치하여 공간의 깊이감(Depth) 형성)

## 2. Lighting & Rendering Setup (라이팅 및 렌더링 설정)

### 💡 Lighting Strategy: "Cinematic Medical Macro"
- **Key Light (Main):** 차가운 화이트(`#FFFFFF`) 톤의 Spot Light. 입자의 형태를 명확히 정의.
- **Rim Light (Backlight):** 따뜻한 Rose Gold 톤의 Rim Light. 입자의 외곽선을 따라 빛을 맺히게 하여 Slate Gray 배경으로부터 분리(Separation)시킴.
- **Fill Light:** 매우 낮은 강도의 Slate Gray 톤 조명. 그림자 영역의 디테일을 확보하되 대비(Contrast)를 해치지 않음.

### 🎞️ Animation Sequence (렌더링 타임라인)
1.  **Phase 1 [Injection]:** 어두운 Slate Gray 공간에 Rose Gold 입자들이 불규칙하게 유입됨 (Motion Blur 적용).
2.  **Phase 2 [Activation]:** 입자가 특정 지점에 머물며 빛을 발산(Emission: `#B76E79`, Strength: `5.0`). 이 빛이 주변 Collagen Fiber에 닿음.
3.  **Phase 3 [Regeneration]:** 입자의 에너지가 전달된 지점에서 Cream 색상의 콜라겐 섬유가 그물망(Mesh) 형태로 촘촘하게 엮이며 구조를 형성함.

## 2. ✍️ Typography & Motion Graphics (Subtitles)

* **Font Style:** 프리미엄 이미지를 위해 획이 깔끔한 **Pretendard (Medium/Bold)** 사용.
* **Text Effect (Rose Gold Glow):**
    * **Color:** `#B76E79` (Rose Gold)
    * **Outer Glow:** 15px Spread, 30% Opacity (Rose Gold 색상)를 적용하여 자막이 배경(Slate Gray)에서 떠오르는 듯한 입체감 부여.
    * **Drop Shadow:** Black, 40% Opacity, Offset 2px (가독성 확보).
* **Motion:** 자막 등장 시 'Fade In'과 함께 미세한 'Scale Up' 효과를 주어 입자의 움직임과 동기화.

## 3. 🎨 Color Grading & Finishing (Color Science)

* **Primary Grade:** 전체 영상의 블랙 레벨을 낮추어 **Deep Slate Gray**의 무게감을 확보.
* **Secondary Grade (Highlight):** Rose Gold 입자의 **Saturation(채도)**와 **Luminance(휘도)**를 15% 상향 조정하여 금속성 광택(Metallic)을 극대화.
* **Texture:** 영상 전체에 2% 미만의 미세한 **Film Grain**을 추가하여 디지털적인 매끄러움 대신 고급스러운 아날로그 질감 부여.

## 4. 🎵 Audio Design (Soundscape)

* **BGM:** 저음역대 베이스가 강조된 **Cinematic Ambient** 트랙 사용. (심장 박동과 유사한 리듬감)
* **SFX (Sound Effects):**
    * 02:00 (Zoom-in): 낮은 저음의 **'Whoosh'** 사운드 삽입.
    * 05:00 (Expansion): 입자가 팽창할 때 미세한 **'Shimmer/Sparkle'** 사운드 삽입.
* **Mastering:** 오디오 피크를 -3dB로 제한하여 모바일 및 웹 환경에서 깨짐 없는 선명한 사운드 전달.

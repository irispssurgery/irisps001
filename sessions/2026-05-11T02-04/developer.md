### 🔍 문제 분석
`DNS_PROBE_FINISHED_NXDOMAIN` 에러는 `jaycorp-internal-storage.com`이라는 도메인이 실제 DNS 서버에 등록되어 있지 않거나 찾을 수 없을 때 발생합니다. 현재 웹 서버/도메인 설정이 완료되지 않았으므로, 웹 링크를 통한 다운로드는 불가능합니다.

이를 해결하기 위해 웹을 거치지 않고 **로컬 파일 시스템에 직접 접근하는 방식**으로 전환합니다.

### 🚀 해결 방법: 로컬 탐색기 즉시 실행

**1. 윈도우 실행 명령어 (CMD/PowerShell용)**
아래 명령어를 복사하여 CMD 또는 PowerShell 창에 붙여넣고 엔터를 누르세요.
```cmd
start explorer "[프로젝트 경로]\sessions\2026-05-11_Final_Render"
```
*(참고: `[프로젝트 경로]` 부분은 실제 프로젝트가 저장된 드라이브 및 폴더 경로로 수정이 필요합니다.)*

**2. 복사용 로컬 경로 (파일 탐색기 주소창 입력용)**
아래 경로를 복사하여 탐색기 상단 주소창에 붙여넣으세요.
```text
[프로젝트 경로]\sessions\2026-05-11_Final_Render
```

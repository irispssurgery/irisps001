# 🎞️ [Project: Retro Glow] 영상 스크립트 및 연출 가이드

본 스크립트는 **'시간이 흘러도 변하지 않는 아름다움'**을 주제로, 90s 레트로 감성과 Mixed Media 기법을 극대화하여 아이리스 성형외과의 브랜드 이미지를 감성적으로 전달하는 데 집중합니다.

| 구분 | 카피 (Text/VO) | 시각적 연출 (Visual) | 기대 효과 |
| :--- | :--- | :--- | :--- |
| **A안 (감성형)** | "당신의 가장 빛나던 순간, 기억하시나요?" | 오래된 캠코더로 찍은 듯한 노이즈 섞인 클로즈업 | 향수를 자극하여 몰입도 유도 |
| **B안 (호기심형)** | "피부에도 기록이 남는다면?" | 피부 결 위로 Doodle 라인이 따라 움직이는 장면 | 시각적 재미와 궁금증 유발 |

## 2. 🎬 Main Script (본문 스크립트)

**컨셉:** *The Timeless Glow (변치 않는 윤기)*
**길이:** 약 20~30초

| Time | Visual (화면 연출) | Audio (사운드/VO) | Text Overlay |
| :--- | :--- | :--- | :--- |
| **00:00~00:03** | **[Hook]** 90s VHS 질감의 화면. 빛바랜 필름 노이즈와 함께 인물의 눈동자 클로즈업. | (Vinyl Crackle) 지직거리는 LP 노이즈 + Lo-fi 비트 시작 | (A안 적용 시) 당신의 가장 빛나던 순간 |
| **00:03~00:12** | **[Development]** 인물의 피부 결을 따라 하얀색 **Doodle 선**이 부드럽게 흐름. 미세한 **Jitter(떨림)** 효과 적용. | 따뜻한 앰비언스 사운드 (바람 소리, 부드러운 피아노 선율) | 시간이 흘러도 변함없는 결 |
| **00:12~00:22** | **[Climax]** 인물의 미소와 함께 화면 전체에 아날로그 질감의 빛 번짐(Light Leak) 발생. 12fps의 스톱모션 느낌 강조. | 비트가 살짝 고조되며 풍성한 앰비언스 결합 | 아이리스가 완성하는 아름다움 |
| **00:22~00:30** | **[Outro]** 아이리스 성형외과 로고 등장. 90s TV 채널 전환 효과(Static)와 함께 마무리. | Lo-fi 비트가 서서히 Fade-out | **IRIS Plastic Surgery** |

## 3. 🛠️ Production Guide (제작 가이드)

### 🎨 Visual Specification (시각적 사양)
* **Frame Rate:** **12fps** 고정 (의도적인 끊김을 통해 아날로그 스톱모션 느낌 구현).
* **Texture:** Heavy Grain, Light Leak, VHS Overlay, Dust & Scratches.
* **Mixed Media:** 
    * 실사 영상 위에 **Hand-drawn Doodle** 레이어 합성.
    * 피사체의 움직임에 따라 Doodle 라인이 따라가는 **Precision Masking** 필수.
* **Color Palette:** 따뜻한 베이지, 빈티지한 세피아, 채도가 낮지만 깊이 있는 톤.

### 🎵 Audio Specification (청각적 사양)
* **Genre:** Lo-fi Hip-hop / Chillhop.
* **Layering:** 
    * Layer 1: Lo-fi Beat (Main Rhythm).
    * Layer 2: Ambient Sound (Nature, Wind, Soft Piano).
    * Layer 3: Retro Texture (Vinyl Crackle, Tape Hiss).

### 📝 Editor's Note (편집자 주의사항)
* **Jitter Control:** 모든 움직임에 미세한 떨림(Jitter Noise)을 추가하여 디지털의 매끄러움을 제거할 것.
* **Transition:** 장면 전환 시 단순 컷 편집보다는 **Film Burn**이나 **TV Static** 효과를 사용하여 서사적 일치성을 유지할 것.

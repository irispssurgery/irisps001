## 1. Brand Visual Concept: "The Precision of Elegance"
**[정의]** 단순한 미적 개선을 넘어, 의학적 정교함(Precision)이 만드는 우아한 결과(Elegance)를 시각화함. 
**[핵심 키워드]** 
- **Authority (권위):** 무게감 있는 컬러와 절제된 레이아웃.
- **Serenity (평온):** 넓은 여백과 부드러운 톤의 사용.
- **Clarity (명확성):** 고해상도 디테일 컷과 명확한 타이포그래피.

## 2. Visual System (Design Guide)

### 🎨 Color Palette
| 역할 | Color Name | Hex Code | 사용 가이드 |
| :--- | :--- | :--- | :--- |
| **Primary** | Iris Midnight Navy | `#1A1C20` | 헤더, 텍스트(H1, H2), 무게감 있는 섹션 배경 |
| **Accent** | Champagne Gold | `#C5A059` | CTA 버튼, 핵심 강조 포인트, 아이콘, 라인 요소 |
| **Base** | Pure White | `#FFFFFF` | 메인 배경, 콘텐츠 영역의 깨끗함 유지 |
| **Sub/Neutral** | Soft Sand / Light Grey | `#F8F9FA` / `#E9ECEF` | 섹션 구분선, 카드 UI 배경, 비활성화 상태 |

### ✍️ Typography
| 용도 | Font Family | Weight | 특징 |
| :--- | :--- | :--- | :--- |
| **Heading (Serif)** | **Cormorant Garamond** | Bold / Medium | 클래식하고 고급스러운 분위기 (Brand Identity) |
| **Body (Sans-serif)** | **Pretendard** | Regular / Medium | 높은 가독성 및 모바일 최적화 (Information) |
| **Sub-copy** | **Pretendard** | Light | 보조 설명 및 캡션 (Minimalism) |

### 🧊 UI Elements & Mood
- **Border Radius:** `0px` (날카롭고 정교한 느낌) 또는 `4px` (최소한의 부드러움).
- **Shadow:** `0px 10px 30px rgba(0, 0, 0, 0.05)` (매우 은은한 그림자로 깊이감만 부여).
- **Spacing (Grid):** 12-Column Grid / Base Unit: `8px`.
- **Interaction:** `Ease-in-out` (0.4s) - 부드러운 페이드 인/아웃 및 슬라이딩.

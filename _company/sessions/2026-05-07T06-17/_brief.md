# 📋 작업 브리프

**원 명령:** 후속 지시가 있을때까지 GitHub Sync  하지 마

## 요약
GitHub 동기화 활동을 즉시 중단하라는 운영 지침입니다. 모든 에이전트는 이 지침을 최우선 순위로 설정하고, 사장님의 명확한 재개 지시가 있기 전까지는 어떠한 온라인 동기화 활동도 진행해서는 안 됩니다.

## 분배
- **📱 영숙**: 시스템 전반에 걸쳐 '온라인 동기화 중단(Sync Disabled)' 상태를 최우선 지침으로 설정하십시오. 이 지침은 모든 에이전트(youtube, instagram, designer, developer 등)의 업무 수행 시 최우선으로 준수되어야 합니다. 동기화 재개는 사장님의 명시적이고 구두적인 지시가 있을 때만 가능함을 모든 에이전트에게 공지하고, 이 상태를 시스템 로그에 명확히 기록하십시오.

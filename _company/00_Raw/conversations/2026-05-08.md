### 1. 근본 원인 분석 (Root Cause Analysis)

**에러 발생 원인:**
`UnicodeEncodeError: 'cp949' codec can't encode character '\u274c'`
1.  **환경적 요인:** Windows 운영체제의 한국어 기본 인코딩은 `CP949`(확장 완성형)입니다. 
2.  **데이터 불일치:** 출력하려는 데이터에 `\u274c`(❌ 이모지)와 같은 유니코드 문자가 포함되어 있으나, CP99 매핑 테이블에 해당 문자가 존재하지 않습니다.
3.  **프로세스 흐름:** Python의 `print()` 함수나 파일 쓰기(`write`) 작업 시, 시스템 기본 인코딩(CP99)을 따르려고 시도하다가 매핑 실패로 인해 런타임 에러가 발생합니다.

### 2. 해결 전략: UTF-8 표준화 (Encoding Standardization)

모든 입출력(I/O) 레이어에서 인코딩을 `utf-8`로 명시적으로 지정하여 인코딩 불일치를 원천 차단합니다.

#### A. 파일 입출력 (File I/O)
`open()` 함수 호출 시 반드시 `encoding='utf-8'` 파라기터를 명시합니다.
```python
# Bad: 시스템 기본값(CP99)에 의존
with open('log.txt', 'w') as f:
    f.write("Error: ❌\n")

# Good: UTF-8로 명시적 지정
with open('log.txt', 'w', encoding='utf-8') as f:
    f.write("Error: ❌\n")
```

#### B. 로깅 시스템 (Logging Module)
`logging` 모듈의 `FileHandler` 생성 시에도 인코딩을 지정해야 합니다.
```python
import logging

# Bad: 기본 인코딩 사용
logging.basicConfig(filename='app.log', level=logging.INFO)

# Good: UTF-8로 명시적 지정
logging.basicConfig(
    filename='app.log', 
    level=logging.INFO, 
    encoding='utf-8',  # Python 3.9+ 에서 지원
    format='%(asctime)s - %(levelname)s - %(message)s'
)
```

`print()` 함수는 시스템의 `sys.stdout` 인코딩을 따릅니다. 런타임 시점에 `sys.stdout`의 인코딩을 `utf-  8`로 재설정하거나, 실행 환경(Terminal)의 환경 변수를 수정합니다.

**파일 경로:** `core/env_config.py`
```python
import sys
import io

def apply_utf8_encoding_patch():
    """
    [Critical] 시스템의 표준 입출력 인코딩을 UTF-8로 강제 설정합니다.
    Windows 환경의 CP949/EUC-KR 인코딩으로 인한 UnicodeEncodeError를 방지합니다.
    """
    try:
        # sys.stdout.buffer (Binary Stream)를 UTF-8로 감싸는 TextIOWrapper로 재정의
        if hasattr(sys.stdout, 'buffer'):
            sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
        
        if hasattr(sys.stderr, 'buffer'):
            sys.io.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding='utf-8', errors='replace')
            
        # 성공 로그 출력 (UTF-8 특수문자 포함 테스트)
        print("[INFO] UTF-8 Encoding Patch Applied Successfully. 🚀✅")
    except Exception as e:
        # 패치 실패 시 최소한의 에러 출력 (기본 인코딩 사용)
        sys.stderr.write(f"[ERROR] Failed to apply UTF-8 patch: {str(e)}\n")

# 시스템 초기화 시 즉시 실행
apply_utf8_encoding_patch()
